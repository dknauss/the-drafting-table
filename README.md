# The Drafting Table

[![License: GPL v2+](https://img.shields.io/badge/License-GPL%20v2%2B-blue.svg)](readme.txt) [![Theme Quality](https://github.com/dknauss/the-drafting-table/actions/workflows/theme-quality.yml/badge.svg)](https://github.com/dknauss/the-drafting-table/actions/workflows/theme-quality.yml) [![Latest Release](https://img.shields.io/github/v/release/dknauss/the-drafting-table)](https://github.com/dknauss/the-drafting-table/releases) [![Docs](https://img.shields.io/badge/docs-available-0a7ea4.svg)](docs/)

A Frank Lloyd Wright-era architect's notebook theme with aged parchment, dot-grid overlays, blueprint borders, and refined architectural typography.

Since 1.0.0 this is a child theme of [Ollie](https://github.com/OllieWP/ollie). The last standalone version is [v0.6.4](https://github.com/dknauss/the-drafting-table/releases/tag/v0.6.4), on the [`standalone`](https://github.com/dknauss/the-drafting-table/tree/standalone) branch. [docs/ollie-port.md](docs/ollie-port.md) explains the port: the preset renames, what is overridden from Ollie, and what to check.

See [`readme.txt`](readme.txt) for the WordPress.org-style theme readme, installation notes, changelog, and release metadata.
